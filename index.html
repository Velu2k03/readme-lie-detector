The lie it caught

The README said

Clicking Add raises the count, and clicking Reset sets the count back to "Count: 0".

The browser showed

Count stayed at 3, even after clicking Reset twice and refreshing.

After the count reached 3, using Reset left the displayed count at 3 instead of returning it to 0.

Caught Nov 14, Gate Shop test fixture, Day 2 gate test. The Reset handler was a no-op, so it was fixed. The Hati demo app below: 8 claims, 8 verified.

How it works

  1. ReadPicks the sentences in the README that a browser can check and copies each expected value from the text.
  2. RunKane CLI performs each claim in a real Chrome and saves a screenshot at every step.
  3. CompareA second check compares the value Kane read with the README value, and classifies a failure as a false claim, a stale doc, or a bad test.
